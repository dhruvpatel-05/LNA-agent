\begin{abstract}
We test whether a large language model (LLM) sentiment score for financial
news headlines, conditioned on contemporaneous limit-order-book order flow
imbalance (OFI), produces a statistically significant Spearman information
coefficient (IC) at 1-, 5-, and 15-minute forward return horizons.
Using LOBSTER level-2 data and claude-haiku-4-5-20251001, we find
\textit{[results to be filled]}.
We report bootstrap confidence intervals, Benjamini--Hochberg FDR correction,
entity-anonymization placebos, and net-of-cost estimates.
\end{abstract}

\section{Introduction and Honest Framing}
\label{sec:intro}

\paragraph{Hypothesis.}
Order flow imbalance reveals latent demand; LLM sentiment reveals the
direction of a news shock.  The interaction signal $\text{OFI}_t \times
\text{sent}_t$ should predict short-horizon returns better than either
component alone.

\paragraph{Honest framing.}
This is an academic feasibility study, not a live trading system.
Sample sizes are small (\textasciitilde{}300 events per ticker over 2--4
years).  Data for one ticker (AAPL) was used during pipeline development;
remaining tickers are held out.  All reported $p$-values are two-sided
and FDR-corrected; we do not mine horizons post-hoc.

%% ── 3. Methodology ───────────────────────────────────────────────────────────
\section{Methodology}
\label{sec:method}

\subsection{Sentiment Scoring}
Three scorers are compared:
\begin{itemize}
  \item \textbf{LM} — Loughran--McDonald finance lexicon (offline).
  \item \textbf{FinBERT} — \texttt{ProsusAI/finbert}; score $= p_+ - p_-$.
  \item \textbf{LLM} — \texttt{claude-haiku-4-5-20251001}; output $\in [-1, 1]$;
        system prompt cached via \texttt{cache\_control: ephemeral}.
\end{itemize}

\subsection{Order Flow Imbalance}
OFI is computed from 1-minute LOB snapshots per Cont, Kukanov \&
Stoikov (2014) and z-scored within each trading day.

\subsection{IC Evaluation}
Spearman IC with 5000-replicate percentile bootstrap CIs.
Multiple testing: Benjamini--Hochberg FDR at $q = 0.05$ across all
strategy $\times$ horizon cells.

\subsection{Conditional OFI Regression}
\begin{equation}
  r_{t+h} = \alpha + \gamma\,\text{OFI}_t
  + \delta_1\,\text{sent}^+_t + \delta_2\,\text{sent}^-_t
  + \beta^+(\text{OFI}_t \cdot \text{sent}^+_t)
  + \beta^-(\text{OFI}_t \cdot \text{sent}^-_t)
  + \varepsilon_t
\end{equation}
where $\text{sent}^+ = \max(\text{sent}, 0)$,
$\text{sent}^- = \min(\text{sent}, 0)$.
Standard errors: Newey--West HAC (overlapping labels) and cluster-robust
(by event and by day).  Wald test: $H_0\colon \beta^+ = \beta^-$.

%% ── 5. Limitations ───────────────────────────────────────────────────────────
\section{Limitations}
\label{sec:limits}

\begin{itemize}
  \item Small per-ticker sample sizes; IC estimates are noisy.
  \item News source may introduce look-ahead if timestamps are publication
        times rather than wire-release times.
  \item LOBSTER data covers regular hours only; pre/post-market reactions omitted.
  \item LLM API cost makes large-scale replication expensive.
  \item No out-of-sample test beyond held-out tickers.
\end{itemize}


%% ── 6. Route to Publication ──────────────────────────────────────────────────
\section{Route to Publication}
\label{sec:publication}

To strengthen this work for submission to a peer-reviewed venue:
\begin{enumerate}
  \item Expand to $\geq 10$ tickers with 3--5 year histories.
  \item Replace TF-IDF baseline embeddings with sentence-transformer features.
  \item Add a proper out-of-sample split (e.g., train 2016--2019, test 2020--2021).
  \item Investigate higher-frequency (10-second) LOB data to reduce lag.
  \item Address the entity-anchoring placebo results — if IC drops $>50\%$
        under anonymization, the signal may reflect name recognition more
        than content.
\end{enumerate}
